# Hi there! 👋 I'm Berk Gezgin

**AI Engineer · Computer Vision · Medical Imaging · Deep Learning**

> AI Engineer at **CranioCatch**, building end-to-end computer vision pipelines for clinical environments.  
> I work with DICOM, NIfTI, 2D radiographs, and intraoral images — from raw data to production-ready diagnostic tools actively used in real clinical settings.

---

## 🔬 What I Work On

- 3D/2D segmentation, detection & landmark detection on CT volumes and dental X-rays (Panoramic, Bitewing, Periapical, Lateral Cephalometric)
- Automated clinical report generation (paranasal airway volumetrics, TMJ assessment, implant evaluation, third molar classification)
- Bone loss quantification & clinically accurate periodontal measurement algorithms
- Facial soft tissue measurement pipelines from Smile / Rest / Profile photographs
- DICOM–STL registration workflows for anatomical consistency across modalities
- End-to-end automated training pipelines covering dataset preprocessing, train/validation/test split, model training, evaluation, and structured reporting — fully automated from raw data to final results
